## Features

- 🎤 **Personalized Rap Generation** — Describe any personality in natural language
- 🤖 **AI Lyrics** — Google Gemini generates structured, personalized rap lyrics
- 🎵 **Real Music** — Replicate (MusicGen) generates instrumentals; ElevenLabs adds vocals
- 🎮 **Immersive 3D Scene** — Original animated character in a neon music studio
- 💃 **Performance Animations** — Beat-driven nodding, gestures, lip sync via audio amplitude
- 📊 **Real-time Status** — Live generation progress polling
- 🎧 **Full Audio Player** — Play, pause, seek, volume, download
- 📜 **Lyrics Panel** — Expandable structured lyrics display
- 🔒 **Secure** — Server-side API keys, Supabase RLS, rate limiting

## Architecture Overview

```
┌────────────────────────────────────────────────────────────┐
│                        Browser                             │
│  Next.js App (React Three Fiber + Framer Motion + Zustand) │
│  3D Scene ←→ UI Overlay ←→ Audio Player                   │
└──────────────────────┬─────────────────────────────────────┘
                       │ fetch /api/*
┌──────────────────────▼─────────────────────────────────────┐
│              Next.js API Routes (Server)                   │
│  POST /api/songs → validates → creates DB record → starts  │
│                    background job via setImmediate          │
│  GET  /api/songs/:id/status → returns progress             │
└──────┬────────────────────────────────────────┬────────────┘
       │                                        │
┌──────▼──────┐                    ┌────────────▼────────────┐
│   Supabase  │                    │   AI Providers          │
│  PostgreSQL │                    │  • Gemini (lyrics)      │
│  Storage    │                    │  • Replicate (music)    │
│  Auth       │                    │  • ElevenLabs (vocals)* │
└─────────────┘                    └─────────────────────────┘
```

**MVP approach:** Background jobs run as in-process async tasks via `setImmediate`. For production scale, upgrade to RabbitMQ (see docker-compose.yml).

## Quick Start

### Prerequisites

- Node.js 20+
- npm 10+
- Supabase project (free tier works)
- Google Gemini API key (free tier available)
- Replicate API token (for music)

### 1. Clone and install

```bash
git clone https://github.com/your-username/vibe2verse.git
cd vibe2verse
npm install
```

### 2. Configure environment

```bash
cp .env.example .env.local
# Edit .env.local with your API keys
```

### 3. Apply database schema

See [Database Setup](#database-setup-supabase) below.

### 4. Run development server

```bash
npm run dev
# Open http://localhost:3000
```

## Environment Variables

Copy `.env.example` to `.env.local` and configure:

| Variable | Required | Description |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | ✅ | Your Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ✅ | Supabase anon/public key |
| `SUPABASE_SERVICE_ROLE_KEY` | ✅ | Supabase service role key (server-only!) |
| `GEMINI_API_KEY` | ✅ | Google Gemini API key |
| `REPLICATE_API_TOKEN` | ⚠️ | Replicate token (music generation) |
| `ELEVENLABS_API_KEY` | ⚠️ | ElevenLabs key (rap vocals) |
| `ELEVENLABS_VOICE_ID` | ⚠️ | ElevenLabs voice ID |

> **Without Replicate/ElevenLabs**: The app still works. Lyrics are generated by Gemini, and the status reaches "completed" using the mock provider. A UI message explains that audio requires a configured provider.

## Database Setup (Supabase)

### Option A: SQL Editor (Recommended)

1. Go to your Supabase project → **SQL Editor**
2. Open `supabase/migrations/001_initial_schema.sql`
3. Paste the entire file and click **Run**

### Option B: Supabase CLI

```bash
npm install -g supabase
supabase login
supabase link --project-ref <your-project-ref>
supabase db push
```

### Verify

After running the migration:

```sql
SELECT tablename, rowsecurity FROM pg_tables WHERE schemaname = 'public';
```

You should see: `profiles`, `songs`, `song_lyrics`, `generation_jobs`, `song_events`, `generation_outbox` — all with RLS enabled.

### Storage Buckets

The migration creates `audio` and `covers` buckets. Verify in Supabase Dashboard → Storage.

## AI Provider Setup

### Google Gemini (Lyrics — Required)

1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Create an API key
3. Add to `.env.local`: `GEMINI_API_KEY=your-key`

**Cost**: Free tier allows ~1500 requests/day.

### Replicate (Music Generation — Recommended)

1. Sign up at [replicate.com](https://replicate.com)
2. Get your API token from account settings
3. Add to `.env.local`: `REPLICATE_API_TOKEN=your-token`

**Model used**: `meta/musicgen` (stereo-large)  
**Cost**: ~$0.01–0.05 per generation. Set usage limits in Replicate dashboard.  
**Limitation**: MusicGen generates instrumental music only (no vocals). The prompt guides the style.

### ElevenLabs (Vocal Rap — Optional)

1. Sign up at [elevenlabs.io](https://elevenlabs.io)
2. Get API key and choose/clone a rapper voice
3. Add to `.env.local`: `ELEVENLABS_API_KEY=...` and `ELEVENLABS_VOICE_ID=...`

> **Note**: ElevenLabs TTS over instrumental is the MVP approach for vocals. A future upgrade would use a provider that generates song + vocals together (e.g., Suno when they open their official API).

### Mock Provider (Development)

If no `REPLICATE_API_TOKEN` is set, the app uses a mock provider that:
- Returns a royalty-free sample audio URL for UI testing
- Simulates generation progress
- Does NOT generate real music

Set `MUSIC_PROVIDER=mock` to force mock mode.

## API Reference

### `POST /api/songs`

Create a song generation request.

**Body:**
```json
{
  "personality_input": "Rahul is always late...",
  "character_name": "Rahul",
  "language": "hinglish",
  "rap_style": "funny_comedy",
  "mood": "funny",
  "roast_level": "mild",
  "requested_duration_seconds": 60
}
```

**Response:** `202 Accepted`
```json
{ "id": "uuid", "status": "pending", "progress": 0 }
```

### `GET /api/songs/:id/status`

Poll for generation progress.

**Response:**
```json
{
  "id": "uuid",
  "status": "generating_music",
  "progress": 55,
  "title": null,
  "audio_url": null
}
```

When `status === "completed"`, `audio_url` is a signed Supabase Storage URL (valid 1 hour).

### `GET /api/songs/:id`

Full song details including lyrics.

### `DELETE /api/songs/:id`

Delete a song and its audio file.

### `GET /api/health`

Returns service configuration status.

## Deployment

### Vercel (Recommended)

```bash
npm install -g vercel
vercel deploy
```

Set all environment variables in Vercel Dashboard → Project → Environment Variables.

> **Note**: `setImmediate`-based background jobs work on Vercel serverless with timeout limits. For jobs > 10 seconds, use Vercel's background functions or switch to RabbitMQ.

### Self-hosted

```bash
npm run build
npm start
```

## Optional Infrastructure

### When to use RabbitMQ

Upgrade from `setImmediate` to RabbitMQ when:
- You expect > 10 concurrent generation requests
- You need reliable job retry across server restarts
- Generation reliably takes > 10 seconds (Vercel timeout)

```bash
docker compose up -d  # Starts Redis + RabbitMQ
```

Then replace `setImmediate` in `lib/services/songService.ts` with a queue publisher.

### Replacing the 3D Character

The `RapCharacter.tsx` component uses procedural Three.js geometry. To replace with a production rigged GLB model:

1. Place your `.glb` file in `public/models/character.glb`
2. Use `useGLTF('/models/character.glb')` from `@react-three/drei`
3. Map the `characterState` prop to your model's animation actions
4. Wire morph targets / viseme blend shapes for lip sync
